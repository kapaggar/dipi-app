# Android performance baseline - 1.46.2 / 96

Historical analysis captured before implementation. Findings below describe the
baseline commit, not the final release. Source links are pinned to that commit.
For implementation, validation and release status, see the
[2.0.0 performance record](../plans/2026-09-10-desk-performance.md).

Scope: measure and inventory `main`, then propose changes. No implementation, version bump, APK build/install, release, or v7 merge. Reviewed HEAD `9bf094b`, release **1.46.2 / 96**, against AGENTS.md, docs/LIVE-DESK.md and docs/DESIGN.md. Measurements taken 2026-09-10 UTC.

**Result:** course opening has substantial main-thread work: **5,540 ms** in the warm control without UI polling, with **5 of 6 frames janky**. Centre idle was quiet: **140 ms process CPU over 241,923 ms**, **10 ms main CPU**, zero rendered frames, and **zero app bytes during screen-off**. No measured evidence supports changing keep-alive. Endpoint timing/count instrumentation remains unavailable on the installed release; this report separates source-derived counts from device observations.
